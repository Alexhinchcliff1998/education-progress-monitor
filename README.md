# Learning Progress | EdTech Analytics

Summarize fictional skill observations against individualized accuracy targets. The latest window of trials determines whether a target is met, progressing, or has insufficient observations. Human review is required; not an automated education or eligibility decision tool. Never enter actual student records.

```bash
pip install -r requirements.txt
python progress.py
python -m pytest -q
```
Open generated progress_report.html. Independent AI-assisted demonstration.
